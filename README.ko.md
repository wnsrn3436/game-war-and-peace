# 전쟁그리고평화

게임메이커로 만든 RTS다. 주민, 검병, 창병, 기마병 유닛과 회관, 양성소 건물을 두 진영으로 나눠 넣었고 맵에디터를 같이 만들었다.

## 플레이 방법

Releases에서 받아 실행하면 된다.

타이틀에서 시작을 누르면 저장해둔 `.mak` 맵 파일을 골라 그 맵으로 게임을 시작하고, 에디터를 누르면 맵에디터로 들어간다.

에디터에서는 위쪽 버튼으로 유닛과 건물을 골라 화면에 배치하고 시작 자금도 조정할 수 있다. 만든 맵은 편집용과 게임용 두 가지로 저장하고, 불러오기로 다시 연다. 좌우 방향키로 화면을 스크롤한다.


## 구현 원리

맵 저장은 게임메이커의 `game_save` 를 그대로 썼다. 배치한 유닛의 좌표와 종류를 따로 파일 형식으로 만들어 쓰는 대신 게임 상태 전체를 통째로 스냅샷으로 남기는 방식이다. 파일 대화상자에서 확장자를 `.mak` 로 붙여 맵 파일처럼 보이게 했다. 저장 형식을 설계하지 않고도 맵에디터가 동작했다.

화면 스크롤은 작은 더미 오브젝트 하나를 좌우 방향키로 움직이고 뷰가 그 오브젝트를 따라가게 해서 만들었다.
